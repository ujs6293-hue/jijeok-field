# 지적확정측량 현장지원

지적확정측량 성과검사 현장에서 찍은 사진에 **경계선과 지번·지목 라벨(지구 내/외)**을 표시하고, **촬영위치도·현지사진·현지조치사항(당초/수정)** 보고서를 PPT·PDF·워드로 만드는 웹앱입니다. 지금까지 사무실에 돌아와 PPT로 선을 그리고 번호를 붙이던 작업을 현장에서 끝내는 것이 목적입니다.

- 버전: 2026.11.08 (개인용 독립 버전, 시범)
- 작성: 충청남도 토지공간정책과 지적관리팀
- 개발 방식: 생성형 AI(Claude)와 협업해 작성한 초안이며, 업무 적용 전 담당자 검증이 필요합니다.

## 주요 기능

| 구분 | 내용 |
|---|---|
| 경계 데이터 | DXF(블록 포함), SHP(.shp·.dbf·.prj, zip 가능) 불러오기, 지적 좌표 순서(X=북, Y=동) 자동 판별, 지구계·지번·지목 인식 |
| 좌표계 | GRS80 중부·서부·동부원점, Bessel 중부원점(구좌표) 등 |
| 내 위치 | 휴대폰 GPS로 현재 위치·오차 표시, 지구 내/외, 가까운 필지 안내, 따라가기 |
| 현장사진 | 촬영 시 현재 위치 자동 지정(사진 GPS 우선), 지도에서 위치 지정 |
| 경계선 | 색 6종, 두께 7단계, 실선/점선, 직선/곡선, 꼭짓점 이동 |
| 라벨 | 주변 필지 자동 후보 "지구 내 (지번, 지목)", "지구 외", 지번 검색, 직접 입력, 크기 조절·삭제 |
| 배경 | 브이월드 항공사진(인증키 필요), 정사영상 파일(GeoTIFF 또는 JPG·PNG+월드파일) |
| 출력 | PPT(.pptx), PDF, 워드(.docx, 한글에서 열어 HWP로 저장), 사진 묶음(.zip) |
| 기타 | 홈 화면 설치(PWA), 한 번 연 뒤 오프라인 사용 |

## 데이터와 보안

- 경계 데이터, 사진, 표시 내용은 **사용하는 기기의 브라우저 안(IndexedDB)에만 저장**되고 서버로 전송되지 않습니다.
- 이 저장소에는 **프로그램 코드만** 있고 측량성과·사진·개인정보는 없습니다. 예시 데이터의 지번·좌표는 가상 값입니다.
- 외부 연결: 라이브러리(cdn.jsdelivr.net), 글꼴(fonts.googleapis.com), 브이월드 항공사진(api.vworld.kr, 인증키 입력 시).
- 업무 사용 전 확인할 사항: 측량성과를 개인 휴대폰에서 다뤄도 되는지(기관 보안규정), 외부 호스팅 사용 가능 여부, 생성형 AI 산출물 업무 적용 절차.

## 사용 방법

1. **경계 데이터** 버튼 → DXF 또는 SHP 선택 → 좌표계 확인
2. **내 위치**를 켜고 현장에서 **사진 촬영** → 현재 위치가 자동으로 붙음
3. **경계선** 모드에서 경계점표지를 따라 점을 누름 → **라벨** 모드에서 후보를 골라 사진에 놓음
4. 재시공 전후 사진은 사진 목록에서 **조치 당초 / 조치 수정**으로 지정하고 짝을 지음
5. **보고서 출력** 탭에서 PPT·PDF·워드로 저장

## 배포 방법

### GitHub Pages
1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다(`.gitlab-ci.yml`, `.nojekyll` 포함).
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 저장합니다.
3. 몇 분 뒤 `https://아이디.github.io/저장소이름/` 주소로 열립니다.

### 공공 GitLab (gitlab.aigov.go.kr)
1. 새 프로젝트를 만들고 이 폴더의 파일을 모두 올립니다.
2. Pages 기능이 켜져 있으면 `.gitlab-ci.yml`에 따라 자동으로 게시됩니다(**Deploy → Pages**에서 주소 확인). Pages 제공 여부는 운영기관 확인이 필요합니다.

### 브이월드 항공사진
브이월드 오픈API에서 인증키를 발급받을 때 위 배포 주소를 서비스 URL로 등록하고, 앱의 **경계 데이터 → 브이월드 항공사진**에 인증키를 넣습니다.

## 알려진 한계

- `.dat` 성과파일은 직접 읽지 못합니다. DXF 또는 SHP로 변환해 사용합니다.
- 경계가 낱개 선(LINE)으로만 그려진 DXF는 필지·지구 내외 판별이 어렵습니다. 닫힌 폴리라인 또는 SHP를 권장합니다.
- 휴대폰 GPS는 수 m 오차가 있어 라벨 후보·위치도 참고용입니다. 경계 판단의 근거로 쓰지 않습니다.
- 한글(.hwp)은 직접 저장하지 못하므로 워드 파일을 한글에서 열어 HWP로 저장합니다.
- PDF는 쪽 단위 그림으로 저장되어 글자 선택이 되지 않습니다.
- 앱 파일을 수정하면 `sw.js`의 `CACHE` 버전을 올려야 기기에 새 버전이 반영됩니다.
